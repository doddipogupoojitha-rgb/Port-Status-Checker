# Port Status Checker

Python socket utility to check open ports and service responsiveness on a target host.

## Objective
Program network socket connections to audit open host ports.

## Features
- Checks if ports are Open, Closed, or Filtered
- Uses TCP socket handshake with timeout
- Shows results in a table format
- Detects service names

## How to Run
1. Run: python port_checker.py
2. Enter target IP (e.g., 127.0.0.1)
3. Enter start port and end port
4. Output shows port status table
